
### `batch prepare`

Usage: `ksef2 batch prepare [OPTIONS] INVOICE_PATHS...`

Build and encrypt batch parts, then store them for a later submit.

The parts depend on the KSeF encryption key rather than on a session, so preparing
ahead of submitting lets a rejected upload retry without packing and encrypting the
invoices again. The artifact holds a session key and invoice payloads, so keep it
as protected as a credential file.

| Option | Type | Default | Env var | Help |
| --- | --- | --- | --- | --- |
| `INVOICE_PATHS...` | - | required | - | - |
| `--out`, `-o` | DIRECTORY | required | - | Artifact directory. |
| `--form` | [FA2\|FA3\|FA_RR1\|PEF3\|PEF_KOR3] | FA3 | - | Form schema: FA2, FA3, FA_RR1, PEF3, PEF_KOR3. |
| `--offline` | - | false | - | Declare offline invoicing mode. |
| `--max-part-size` | INTEGER RANGE | - | - | - |

### `batch submit`

Usage: `ksef2 batch submit [OPTIONS] [INVOICE_PATHS]...`

Prepare, upload, close, and optionally wait for a batch session.

Pass invoice files to prepare them in one go, or --prepared to upload a package that
batch prepare stored, which is the retry path after a failed upload.

| Option | Type | Default | Env var | Help |
| --- | --- | --- | --- | --- |
| `[INVOICE_PATHS]...` | - | - | - | Invoice XML files to prepare and submit. Leave them out with --prepared. |
| `--prepared` | DIRECTORY | - | - | Artifact directory written by batch prepare. Its parts are uploaded as they are, and --form, --offline, and --max-part-size do not apply. |
| `--state-file` | FILE | - | - | - |
| `--form` | [FA2\|FA3\|FA_RR1\|PEF3\|PEF_KOR3] | FA3 | - | Form schema: FA2, FA3, FA_RR1, PEF3, PEF_KOR3. |
| `--offline` | - | false | - | Declare offline invoicing mode. |
| `--max-part-size` | INTEGER RANGE | - | - | - |
| `--wait` | - | false | - | Wait for batch processing completion. |
| `--timeout` | FLOAT RANGE | 120.0 | - | - |
| `--poll-interval` | FLOAT RANGE | 2.0 | - | - |

### `batch upload`

Send the stored parts again to a batch session whose upload failed.

The state file carries the session reference, keys, and upload instructions, while
the artifact carries the exact parts KSeF expects, so recovering needs neither new
invoices nor a new package.

| Option | Type | Default | Env var | Help |
| --- | --- | --- | --- | --- |
| `--prepared` | DIRECTORY | required | - | Artifact directory written by batch prepare. |
| `--state-file` | FILE | required | - | Batch session state left behind by a failed submit or written by any command that reports session state. |
| `--wait` | - | false | - | Wait for batch processing completion. |
| `--timeout` | FLOAT RANGE | 120.0 | - | - |
| `--poll-interval` | FLOAT RANGE | 2.0 | - | - |

| --- | --- | --- | --- | --- |
| `--description` | TEXT | required | - | Token description. |
| `--permission`, `--permissions` | [invoice_read\|invoice_write\|introspection\|credentials_read\|credentials_manage\|subunit_manage\|enforcement_operations\|collective_identifier_manage] | [] | - | Permission to grant. Repeat for multiple permissions. |
| `--wait` | - | false | - | Wait for the token to become active. |

### `tokens list`

List KSeF authorization tokens.

| Option | Type | Default | Env var | Help |
| --- | --- | --- | --- | --- |
| `--status` | [pending\|active\|revoking\|revoked\|failed] | [] | - | Token status filter. Repeat for multiple. |
| `--description` | TEXT | - | - | - |
| `--author-identifier` | TEXT | - | - | - |
| `--author-identifier-type` | [nip\|pesel\|fingerprint] | - | - | - |
| `--page-size` | INTEGER RANGE | 10 | - | - |
| `--all` | - | false | - | Fetch all pages. |
